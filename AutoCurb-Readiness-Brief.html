What’s real vs. what gates scale

Strengths (verified in code)
  • Best-in-class voice compliance: server-enforced TCPA consent, local calling hours, recording disclosure, opt-out, kill-switch
  • Uncontested category: KBB ICO returns the car to Cox; CarGurus exited acquisition; Edmunds routes to CarMax
  • Deep, real build — 84 edge functions, multi-tenant, OCR + vision condition scoring live
  • Auditable, capped AI re-offer (transparent, not a black box)
Gaps that gate scale
  • AI usage metering / billing is UI-only — no Stripe meter events; “+ metered AI” isn’t enforceable yet
  • No native DMS write — vAuto push is a sandbox stub; #1 enterprise dealbreaker (double entry)
  • Group infra immature — SSO/SAML config-only, no consolidated billing, no SOC 2
  • Voice price-moves need a human-in-the-loop gate; OpenAI voice provider is a stub
  • Pricing config stale ($299/$499 in code vs. $1,495/$2,495 proposed)
Pricing & positioning calls

Basic $1,495 in line (≈ Accu-Trade/VINCUE). Premium $2,495 base + metered AI (drop the flat $3.5k). Add a performance plan ($25–50/acquired unit, capped). Lead message: “You keep the car” + autonomous dead-lead recovery. Enterprise = success-gated pilot → group MSA at 50–65% off. Earn the moat with pilot proof + one native DMS integration.
