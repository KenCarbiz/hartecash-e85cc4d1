# Integration Request Letters

Vendor-facing letters to request bidirectional API integrations with Hartecash. Hand these to the partnership / integration team at each vendor. Fill in the bracketed placeholders ([Dealer Name], [N] rooftops, [X] vehicles/month) with your group's specifics before sending.

| File | Audience | Purpose |
|---|---|---|
| [vauto-integration-request.md](./vauto-integration-request.md) | vAuto (Cox Automotive) | Push acquired vehicles into vAuto inventory; pull vAuto's market data + appraisal values into the Hartecash appraisal screen. |
| [crm-integration-request.md](./crm-integration-request.md) | VinSolutions, DealerSocket, Elead/CDK | Pull customer + deal + finance/lease data into Hartecash to identify equity-position customers; push Hartecash submissions back as leads. |
| [service-drive-integration-request.md](./service-drive-integration-request.md) | Xtime, Dealer-FX, MyKaarma, AutoPoint, Tekion Service | Real-time appointment / RO events so Hartecash can surface a personalized offer at service-lane write-up. |

## How to use

1. Open the letter for the vendor you're approaching.
2. Replace every `[bracketed placeholder]` with your group's specifics.
3. Save as PDF or paste into email.
4. Send to the contact address listed at the top of each file (or use the vendor's standard partner intake form if they require it).

## Suggested order

1. **CRM first** — without CRM data Hartecash can't identify equity customers, which is the biggest revenue lever.
2. **Service drive second** — once CRM data is flowing, service-lane triggers become the highest-converting outreach channel.
3. **vAuto third** — workflow efficiency play, removes lot-tech re-keying and gives the appraiser market data in-flow.
